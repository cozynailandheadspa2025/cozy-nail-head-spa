COZY NAIL & HEAD SPA — SỬA LỖI MẤT ẢNH NAIL ART & MASSAGE

GÓI NÀY CHỈ GỒM 2 ẢNH, KHÔNG GHI ĐÈ index.html / CSS / JAVASCRIPT.

1. Mở GitHub repository cozy-nail-head-spa.
2. Mở lần lượt thư mục assets rồi images.
3. Trong thư mục images, chọn Add file > Upload files.
4. Từ gói vừa giải nén, kéo 2 file dưới đây vào:
   - assets/images/nail-art-feature.webp
   - assets/images/massage-feature.webp
   Nếu GitHub báo file cùng tên, chọn thay thế nếu cần.
5. Commit changes.
6. Đợi GitHub Pages cập nhật (1-5 phút) và thử mở trang bằng cửa sổ Incognito.

Đường dẫn kiểm tra trực tiếp:
https://cozynailandheadspa.com/assets/images/nail-art-feature.webp
https://cozynailandheadspa.com/assets/images/massage-feature.webp

Nếu 2 link ảnh này mở được nhưng ảnh vẫn không xuất hiện trên trang chủ,
chụp ảnh trang hoặc gửi link cụ thể để kiểm tra đường dẫn đang được website sử dụng.
