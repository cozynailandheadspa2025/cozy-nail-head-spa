QUAN TRỌNG — ĐỪNG TRỘN NHIỀU BẢN UPDATE CŨ
1. Vào GitHub repository cozy-nail-head-spa, Download ZIP ở mục Code để backup phiên bản hiện tại.
2. Giải nén bản ZIP này. Upload các FILE VÀ THƯ MỤC Ở BÊN TRONG vào gốc repository (thấy index.html, assets, services cùng cấp). Không upload ZIP hoặc thư mục bọc ngoài.
3. Giữ/replace file trùng tên để sử dụng bản mới. Không xóa CNAME; bản ZIP đã gồm CNAME chuẩn cozynailandheadspa.com.
4. Commit changes. Mở GitHub > Actions để chờ deploy màu xanh.
5. Mở Incognito https://cozynailandheadspa.com/ (không thêm /index.html#experience), bấm Contact ở menu để xem giờ từng ngày và 3 mạng xã hội.
6. Kiểm tra trang Head Spa tại https://cozynailandheadspa.com/services/head-spa.html và đảm bảo video gội đầu chạy.
7. Nếu chưa thấy nội dung mới, thử Ctrl+Shift+R và kiểm tra trong GitHub xem index.html và file CSS đã được upload đúng.

Không cần thay DNS, Namecheap hay domain.
