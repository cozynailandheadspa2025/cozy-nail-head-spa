COZY NAIL & HEAD SPA – CHỈ CẬP NHẬT FAQ 3 CỘT

1. Giải nén file ZIP.
2. Vào repository GitHub cozy-nail-head-spa.
3. Upload file index.html ở THƯ MỤC GỐC và thay file cũ.
4. Bấm Commit changes. Đợi GitHub Pages cập nhật, rồi thử xem bằng Incognito.

THAY ĐỔI DUY NHẤT:
- Business Hours / A Few Questions / Our Location nằm cùng một hàng trên máy tính lớn.
- FAQ giữ 3 câu (booking, dịch vụ, Head Spa); bỏ 2 câu trùng giờ và địa chỉ.
- Trên máy tính bảng và điện thoại, các khung tự xếp để dễ đọc.
- Bỏ khu FAQ riêng nằm dưới Contact & Hours.

Các phần Gallery, Promotion, Call Us, bản đồ, review và footer được giữ nguyên từ bản cập nhật đã chuẩn bị gần nhất.

QUAN TRỌNG: File này được tạo từ bản index.html cập nhật cuối cùng mà chúng ta đã chuẩn bị (sau khi bỏ bảng giờ ở footer). Nếu bạn đã thay đổi index.html trực tiếp trên GitHub sau đó, nên gửi bản hiện hành trước khi ghi đè.
